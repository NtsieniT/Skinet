GETTING REDIS IN MEMORY DATABASE INSTALLED ON WINDOWS

STEP 1: GO TO https://chocolatey.org/install 
STEP 2: OPEN WINDOWS POWERSHELL AND RUN WITH ADMINISTRATOR RIGHTS
STEP 3: INSTALL CHOCOLATEY USING POWERSHELL 
		COMMAND 'Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://chocolatey.org/install.ps1'))'
		- THIS WILL ALSO BYPASS GET-EXECUTIONPOLICY TO GET THINGS INSTALLED OR SIMPLY ENSURE GET-EXECUTIONPOLICY IS NOT RESTRICTED
		- THIS WILL INSTALL CHOCOLATEY ON THE WINDOWS MACHINE WHICH IS USED TO RUN REDIS.
		- WAIT FOR INSTALLATION TO COMPLETE
STEP 4: - ONCE INSTALLATION HAS BEEN COMPLETED, INSTALLRED IS USING THE FOLLOWING COMMAND
		- COPY AND PASTE COMMAND 'choco install redis-64 --version=3.0.501' AND PASTE ON POWERSHELL RUNNING WITH ADMIN RIGHTS.
		
STEP 5: ONCE INSTALLATION IS COMPLETE, RUN COMMAND 'REDIS-SERVER' TO RUN THE SERVER AND GET THE PORT NUMBER
